# Web capability index

Find an existing owner here, then inspect its API and example. Examples show
wiring; [DESIGN.md](../../../../DESIGN.md) and module contracts define behavior.

| Task | Existing owner and source | Fit and current consumer |
|---|---|---|
| Browse, inspect, create, or edit records | [Resource bindings](../../../../packages/loom/src/resources/bindResource.ts), [ListView](../../../../packages/loom/src/components/views/ListView.vue), [DetailView](../../../../packages/loom/src/components/views/DetailView.vue), [FormView](../../../../packages/loom/src/components/views/FormView.vue) | Use Views and slots, or complete bound primitive bags for embedded content. [Users resource](../../../../apps/web/src/routes/%28authenticated%29/settings/users/users.resource.ts) and [edit page](../../../../apps/web/src/routes/%28authenticated%29/settings/users/%5BuserId%5D/edit.route.vue) show route-owned confirmation. |
| Select related records from an existing read | [CheckboxGroupInput](../../../../packages/loom/src/components/inputs/CheckboxGroupInput.vue) and [option source](../../../../packages/loom/src/components/inputs/useOptionSource.ts) | Supply identity, label, scope, and form conversion; the input owns loading and selection. [Users role field](../../../../apps/web/src/routes/%28authenticated%29/settings/users/users.resource.ts) uses `roles.actions.list`. |
| Pick related records through a searchable table | [LookupInput](../../../../packages/loom/src/components/composites/form-inputs/LookupInput.vue) | Owns picker query, staged selection, and hydration. Supply scoped loaders. See [owner examples](../../../../packages/loom/src/components/composites/__tests__/LookupInput.spec.ts). |
| Add, edit, remove, or reorder parent-form rows | [TableInput](../../../../packages/loom/src/components/composites/form-inputs/TableInput.vue) | Owns row identity, draft, and errors in dialog or inline mode. See [current row examples](../../../../packages/loom/src/components/composites/__tests__/TableInput.browser.spec.ts) and the [inline contract](../../../../packages/loom/README.md#local-controls-and-form-state). |
| Collect contextual input in a dialog | [DialogForm](../../../../packages/loom/src/components/composites/DialogForm.vue) | Pass flat Form props. The dialog owns the Form session and close lifecycle; record-dependent resolution stays with FormView. See [compiled bindings](../../../../packages/loom/src/components/composites/__type-tests__/flat-form-components.type-test.vue). |
| Export records or a custom report | [ListView and DetailView exports](../../../../packages/loom/src/exports/README.md) and [Spool](../../../../packages/spool/README.md) | Views own access, data loading, and display mapping. Spool owns document preparation and output. |
| Run a record command from custom row controls | [Resource commands](../../../../packages/loom/src/resources/bindResource.ts) | The resource owns access and invalidation; the page owns feedback. [Role assignment page](../../../../apps/web/src/routes/%28authenticated%29/settings/users/%5BuserId%5D/detail/role-assignments/index.route.vue) uses `withContext`, `can`, and `run`; its [resource](../../../../apps/web/src/routes/%28authenticated%29/settings/users/%5BuserId%5D/detail/role-assignments/role-assignments.resource.ts) declares the command. |
| Keep a record summary visible across child sections | [Tabs](../../../../packages/loom/src/components/composites/Tabs.vue) and [AppRouterView](../../../../apps/web/src/components/routing/AppRouterView.vue) | Routes own page lifetime and the default child. [User detail](../../../../apps/web/src/routes/%28authenticated%29/settings/users/%5BuserId%5D/detail.route.vue) uses both. |
| Select a location with search or a map | [LocationInput](../../../../packages/loom/src/components/composites/form-inputs/LocationInput.vue) | The app supplies provider operations. [Map preview](../../../../apps/web/src/routes/%28authenticated%29/map-preview/index.route.vue) shows the binding. |
| Compose a form and collection without page Views | [Form](../../../../packages/loom/src/components/core/Form.vue), [Table](../../../../packages/loom/src/components/core/Table.vue), [useCollection](../../../../packages/loom/src/components/core/useCollection.ts) | Retain session, query, access, and cache owners. The [query ownership fixture](../../../../apps/web/src/framework/acceptance/QueryOwnershipFixture.vue) compiles this composition. |
